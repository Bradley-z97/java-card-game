Java Card Game

## Compiling and Running
Open the game in Visual Studio Code

The Java Extension Pack is required to compile and run the game

To run the game:
Add input pack into folder (must be a .txt file with 8n lines of positive integers,
where n is the number of players)
type into the terminal:
java CardGame

To run the executable jar file, open the terminal and type:
java -jar cards.jar

## Running the Tests

The tests are written in JUnit 5 and are located in the folder, 'test'

To run the tests:
Open the project in VS Code
Open the Testing panel on the left
Select arrow next to cardsTest to run the suite

These results will appear in the testing panel
